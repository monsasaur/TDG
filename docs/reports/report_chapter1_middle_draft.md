# บทนำ

## ความเป็นมาของโครงการ

ประเทศไทยกำลังเข้าสู่สังคมผู้สูงอายุอย่างชัดเจน โดยสำนักงานสถิติแห่งชาติรายงานว่า ในปี พ.ศ. 2567 ประเทศไทยมีประชากรอายุ 60 ปีขึ้นไปจำนวนประมาณ 14,027,411 คน และมีสัดส่วนมากกว่าร้อยละ 20 ของประชากรทั้งหมด ซึ่งสะท้อนว่าประเทศไทยเข้าสู่สังคมสูงวัยอย่างสมบูรณ์แล้ว (สำนักงานสถิติแห่งชาติ, 2567) การเปลี่ยนแปลงโครงสร้างประชากรดังกล่าวทำให้ครอบครัวและผู้ดูแลต้องรับภาระในการดูแลผู้สูงอายุมากขึ้น โดยเฉพาะผู้สูงอายุที่อยู่ตามลำพัง อยู่กับคู่สมรสสูงวัย หรือมีโรคประจำตัวที่ทำให้การเคลื่อนไหวและการทรงตัวลดลง

ปัญหาการหกล้มเป็นหนึ่งในความเสี่ยงสำคัญของผู้สูงอายุ องค์การอนามัยโลกระบุว่าการหกล้มเป็นสาเหตุการเสียชีวิตจากการบาดเจ็บโดยไม่ตั้งใจเป็นอันดับที่สองของโลก และผู้สูงอายุมากกว่า 60 ปีเป็นกลุ่มที่มีจำนวนการเสียชีวิตจากการหกล้มสูงที่สุด (World Health Organization, 2021) สำหรับประเทศไทย กรมควบคุมโรคระบุว่าผู้สูงอายุประมาณ 1 ใน 3 มีเหตุหกล้มทุกปี หรือมากกว่า 4 ล้านคน และมากกว่าร้อยละ 60 เกิดเหตุนอกบริเวณบ้าน (กรมควบคุมโรค, 2567) หากไม่มีผู้พบเห็นหรือไม่มีการแจ้งเตือนอย่างทันท่วงที เหตุการณ์หกล้มอาจนำไปสู่การบาดเจ็บรุนแรง ภาวะแทรกซ้อน หรือความล่าช้าในการช่วยเหลือ

ระบบตรวจจับการล้มที่ใช้อยู่ทั่วไปมักอาศัยกล้องวงจรปิดหรืออุปกรณ์สวมใส่ เช่น นาฬิกาอัจฉริยะและเซนเซอร์ติดตัว อย่างไรก็ตาม กล้องอาจกระทบต่อความเป็นส่วนตัวของผู้สูงอายุภายในบ้าน และมีข้อจำกัดด้านมุมมอง แสงสว่าง และพื้นที่ติดตั้ง ส่วนอุปกรณ์สวมใส่อาจเกิดปัญหาผู้สูงอายุลืมสวมใส่ ไม่สะดวกต่อการใช้งาน หรือไม่เหมาะกับการใช้งานตลอดเวลา งานวิจัยด้านการตรวจจับกิจกรรมมนุษย์จึงให้ความสนใจกับแนวทางแบบไม่ต้องติดอุปกรณ์กับร่างกาย โดยใช้สัญญาณวิทยุและข้อมูล Channel State Information (CSI) จาก WiFi ซึ่งสามารถตรวจจับการเปลี่ยนแปลงของสัญญาณที่เกิดจากการเคลื่อนไหวของมนุษย์ และมีข้อดีด้านความเป็นส่วนตัวเมื่อเทียบกับระบบที่ใช้ภาพจากกล้อง (Damodaran et al., 2020)

จากปัญหาและแนวโน้มดังกล่าว ผู้พัฒนาจึงจัดทำโครงการระบบตรวจจับการล้มของผู้สูงอายุด้วย WiFi CSI และแอปพลิเคชันแจ้งเตือนผู้ดูแล โดยระบบใช้บอร์ด ESP32 สำหรับเก็บข้อมูลสัญญาณ WiFi CSI แล้วส่งข้อมูลเข้าสู่บริการประมวลผลด้วยโมเดลเรียนรู้ของเครื่อง เพื่อตรวจจับว่าเหตุการณ์นั้นเป็นการล้มหรือไม่ เมื่อระบบตรวจพบการล้ม จะบันทึกเหตุการณ์ ส่งการแจ้งเตือนไปยังแอปพลิเคชัน Middle ของผู้ดูแล และรอให้ผู้ดูแลกดยืนยันการรับทราบ หากไม่มีการตอบรับภายในเวลาที่กำหนด ระบบจะยกระดับการแจ้งเตือนผ่านบริการโทรศัพท์อัตโนมัติ เพื่อเพิ่มโอกาสให้ผู้สูงอายุได้รับความช่วยเหลืออย่างรวดเร็วโดยไม่ต้องพึ่งกล้องหรืออุปกรณ์สวมใส่

## วัตถุประสงค์ของโครงการ

- เพื่อพัฒนาระบบตรวจจับการล้มของผู้สูงอายุโดยใช้ข้อมูล WiFi CSI จากอุปกรณ์ ESP32
- เพื่อพัฒนาโมเดลเรียนรู้ของเครื่องสำหรับจำแนกเหตุการณ์การล้มและเหตุการณ์ที่ไม่ใช่การล้ม
- เพื่อพัฒนา Backend API สำหรับรับข้อมูลจากอุปกรณ์ ประมวลผลร่วมกับบริการ Machine Learning บันทึกเหตุการณ์ และจัดการขั้นตอนการแจ้งเตือน
- เพื่อพัฒนาแอปพลิเคชัน Middle สำหรับผู้ดูแลให้สามารถรับการแจ้งเตือน ดูรายละเอียดเหตุการณ์ และกดยืนยันการรับทราบได้
- เพื่อพัฒนากลไกการแจ้งเตือนต่อเนื่อง เมื่อผู้ดูแลไม่ตอบรับภายในเวลาที่กำหนด โดยยกระดับการแจ้งเตือนผ่านบริการโทรศัพท์อัตโนมัติ

## ขอบเขตของโครงการ

โครงการระบบตรวจจับการล้มของผู้สูงอายุด้วย WiFi CSI และแอปพลิเคชันแจ้งเตือนผู้ดูแล มีขอบเขตการดำเนินงานดังต่อไปนี้

- ขอบเขตด้านอุปกรณ์ตรวจจับ ใช้บอร์ด ESP32 จำนวน 2 ตัวสำหรับสร้างและรับสัญญาณ WiFi CSI โดยตัวหนึ่งทำหน้าที่ส่ง packet และอีกตัวทำหน้าที่รับสัญญาณ CSI เพื่อใช้เป็นข้อมูลสำหรับการตรวจจับการเคลื่อนไหว
- ขอบเขตด้านข้อมูล ใช้ข้อมูล CSI ที่ผ่านการแปลงเป็นคุณลักษณะจำนวน 416 ค่า จากข้อมูล subcarrier และค่าสถิติที่เกี่ยวข้อง เพื่อส่งให้บริการ Machine Learning ประมวลผล
- ขอบเขตด้านโมเดล ใช้โมเดลเรียนรู้ของเครื่องสำหรับจำแนกผลเป็น 2 ประเภท ได้แก่ fall และ no_fall โดยต้นแบบปัจจุบันใช้โมเดล Random Forest และกำหนดค่า threshold สำหรับตัดสินผลการล้ม
- ขอบเขตด้าน Backend พัฒนา Express API เพื่อรับข้อมูลจากอุปกรณ์ เรียกใช้บริการ Machine Learning บันทึกเหตุการณ์การล้ม จัดการ API key ส่ง Push Notification และจัดการการยืนยันรับทราบเหตุการณ์
- ขอบเขตด้านฐานข้อมูล ใช้ Supabase สำหรับจัดเก็บเหตุการณ์การล้ม สถานะการยืนยันรับทราบ สถานะการยกระดับการแจ้งเตือน และข้อมูล Push Token ของอุปกรณ์ผู้ดูแล
- ขอบเขตด้านแอปพลิเคชันผู้ดูแล พัฒนาแอปพลิเคชัน Middle ด้วย React Native และ Expo เพื่อแสดงรายการแจ้งเตือน แยกบ้านหรืออุปกรณ์ ดูรายละเอียดเหตุการณ์ รับ Push Notification และกดยืนยันการตรวจสอบเหตุการณ์
- ขอบเขตด้านการแจ้งเตือน ใช้ Expo Push Notification เป็นการแจ้งเตือนหลัก และใช้ Twilio Voice Call สำหรับการยกระดับการแจ้งเตือนเมื่อไม่มีการตอบรับภายในเวลาที่กำหนด
- ขอบเขตด้านการทดสอบ ทดสอบการทำงานแบบต้นแบบในสภาพแวดล้อมที่กำหนด ได้แก่ การส่งข้อมูล CSI การเรียกใช้งาน API การประมวลผลโมเดล การบันทึกเหตุการณ์ การแจ้งเตือนบนแอป และการกดยืนยันรับทราบ
- โครงการนี้ไม่ใช่ระบบวินิจฉัยทางการแพทย์ ไม่สามารถทดแทนการดูแลจากบุคลากรทางการแพทย์หรือผู้ดูแลโดยตรง และยังไม่ครอบคลุมการติดตั้งใช้งานจริงในทุกสภาพแวดล้อมของบ้านหรือศูนย์ดูแลผู้สูงอายุ

## ซอฟต์แวร์และฮาร์ดแวร์ที่ใช้พัฒนา

ซอฟต์แวร์

- Visual Studio Code สำหรับเขียนและจัดการโค้ดของระบบ
- Node.js และ Express สำหรับพัฒนา Backend API
- Python และ FastAPI สำหรับพัฒนา Machine Learning Service
- Scikit-learn สำหรับสร้างและใช้งานโมเดล Random Forest
- React Native และ Expo สำหรับพัฒนาแอปพลิเคชัน Middle บนอุปกรณ์เคลื่อนที่
- Expo Notifications สำหรับส่งและรับ Push Notification
- Supabase สำหรับจัดเก็บข้อมูลเหตุการณ์และ Push Token
- Twilio สำหรับบริการโทรศัพท์อัตโนมัติเมื่อเกิดเหตุการณ์ที่ไม่มีการตอบรับ
- ESP-IDF หรือเครื่องมือที่เกี่ยวข้องกับ ESP32 สำหรับพัฒนาและติดตั้งโปรแกรมบนบอร์ด ESP32
- Git และ GitHub สำหรับควบคุมเวอร์ชันของซอร์สโค้ด

ฮาร์ดแวร์

- คอมพิวเตอร์สำหรับพัฒนาและทดสอบระบบ
- บอร์ด ESP32 จำนวน 2 ตัว สำหรับส่งและรับสัญญาณ WiFi CSI
- สาย USB สำหรับเชื่อมต่อและรับข้อมูลจาก ESP32
- สมาร์ตโฟนระบบ Android หรือ iOS สำหรับติดตั้งและทดสอบแอปพลิเคชัน Middle
- เครือข่าย WiFi หรือ Hotspot สำหรับเชื่อมต่ออุปกรณ์และทดสอบการส่งข้อมูล
- พื้นที่ทดสอบภายในอาคารสำหรับจำลองเหตุการณ์การล้มและเหตุการณ์ที่ไม่ใช่การล้ม

## ประโยชน์ที่ได้รับ

- ได้ระบบต้นแบบสำหรับตรวจจับการล้มของผู้สูงอายุโดยไม่ต้องใช้กล้องและไม่ต้องให้อุปกรณ์ติดอยู่กับร่างกายผู้สูงอายุ
- ช่วยให้ผู้ดูแลได้รับการแจ้งเตือนเมื่อระบบตรวจพบเหตุการณ์ที่อาจเป็นการล้ม และสามารถตรวจสอบสถานการณ์ได้เร็วขึ้น
- ลดความเสี่ยงจากการที่เหตุการณ์การล้มไม่มีผู้พบเห็น โดยมีขั้นตอนการยืนยันรับทราบและยกระดับการแจ้งเตือนเมื่อไม่มีการตอบรับ
- ได้แนวทางการประยุกต์ใช้ WiFi CSI ร่วมกับ Machine Learning สำหรับงานดูแลผู้สูงอายุและระบบบ้านอัจฉริยะ
- ได้ฐานข้อมูลเหตุการณ์การล้มที่สามารถนำไปใช้วิเคราะห์ ปรับปรุงโมเดล และพัฒนาระบบแจ้งเตือนให้เหมาะสมยิ่งขึ้นในอนาคต
- เพิ่มประสบการณ์ในการพัฒนาระบบแบบครบวงจร ตั้งแต่อุปกรณ์ IoT, Machine Learning, Backend API, Database, Push Notification และ Mobile Application
