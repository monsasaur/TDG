# ทดสอบบนมือถือจริง — รายการเดียวจบ (เขียน 13 พ.ย. 2026)

ของที่ทำในรอบ 12–13 พ.ย. ทดสอบบนเว็บ (ตอบ Supabase ด้วยข้อมูลปลอม) และฐานข้อมูลในเครื่องเท่านั้น
รายการนี้ไล่ทุกอย่างที่**ยังไม่เคยลองบนมือถือ** เรียงตามลำดับที่ทำต่อกันได้ในรอบเดียว

ติ๊ก ☐ → ☑ ระหว่างทำ · ไม่ผ่านให้ดูคอลัมน์ "ถ้าไม่ผ่าน" ก่อน

## เตรียมก่อน

| | ทำอะไร | ทำไม |
|---|---|---|
| ☐ | **build dev client ใหม่** (`npx expo run:android` หรือ EAS) | AsyncStorage เป็น native module — dev client เดิมไม่มี login จะไม่จำข้ามการปิดแอป |
| ☐ | เครื่อง 2 เครื่อง (A = เจ้าของบ้าน · B = ผู้ดูแล) + บัญชีคนละเบอร์ | ช่วง B ต้องใช้สองคน |
| ☐ | Express ต่อ Supabase ด้วย **service_role** · `node scripts/check_live_setup.js` ไม่มี ❌ | เหตุการณ์ต้องลงฐานข้อมูลจริง แอปถึงจะเห็น |
| ☐ | อุปกรณ์ที่ใช้ทดสอบลงทะเบียนในตาราง `devices` และผูกกับบ้านแล้ว (เช่น `ESP-B96AB8`) | ใช้เป็น `device_id` ตอนยิง `/demo/fire` |

ยิงเหตุการณ์ทดสอบ: `POST /api/v1/demo/fire` ด้วย DEMO key · body `{"device_id": "ESP-B96AB8"}`

## ช่วง B — หลังรัน `accounts.sql` (เครื่อง A + B)

| | ทดสอบ | ผลที่ต้องได้ | ถ้าไม่ผ่าน |
|---|---|---|---|
| ☐ B1 | A เปิดหน้าบ้าน · B (บัญชีใหม่) เปิดหน้าบ้าน | A เห็นบ้านเดิมพร้อมป้าย "เจ้าของบ้าน" · B ไม่เห็นบ้านไหน | A ไม่เห็น = ยังไม่รันคำสั่งยกบ้าน / เบอร์ในคำสั่งผิด |
| ☐ B2 | A: สมาชิก → เพิ่มสมาชิก → รหัสบ้าน · B: บ้าน → กรอกรหัสบ้าน | B เข้าร่วมได้ เห็นบ้าน อุปกรณ์ การแจ้งเตือน | "ยังไม่ได้เปิดระบบบัญชีบนฐานข้อมูล" = accounts.sql ยังไม่ได้รัน |
| ☐ B3 | A: เชิญด้วย **QR** · B: สแกนด้วยกล้อง (ลองแบบเลือกรูปจากเครื่องด้วย) | เข้าร่วมได้ทั้งสองแบบ | กล้องไม่เปิด = ยังไม่ได้ให้สิทธิ์กล้อง |
| ☐ B4 | B ยิงซ้ำด้วยรหัสเดิม | "รหัสนี้ถูกใช้ไปแล้ว" | — |
| ☐ B5 | ยิง demo | **A และ B ได้ push** · เครื่องที่ไม่ได้ login หรือไม่ใช่สมาชิก**ไม่ได้** | ไม่มีใครได้ = เครื่องยังไม่ผูกบัญชี (login ใหม่) หรือ demo ใช้ device_id ที่ไม่ได้ผูกกับบ้าน |
| ☐ B6 | B กดรับทราบ | ไม่มีสายโทร · A เห็น "รับทราบโดย <ชื่อ B>" | 401 = token หมดอายุ (ปิด–เปิดแอป) · 403 = B ไม่ได้เป็นสมาชิกบ้านของอุปกรณ์ |

## ที่ยังทดสอบไม่ได้ในรอบนี้

- ส่ง WiFi ให้บอร์ดผ่าน BLE จนจบ + ปุ่ม BOOT ค้าง 5 วิ — ต้องใช้ firmware โหมด production (`CONFIG_ENABLE_BLE_PROVISIONING=y`)
- ลืมรหัสผ่าน — ยังไม่มี (ต้องใช้ OTP ทาง SMS)
