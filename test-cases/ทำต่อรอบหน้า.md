## วิธีรัน

ปิดไฟล์ Excel ก่อนทุกครั้ง รันจากโฟลเดอร์ `test-cases`

```powershell
python tools/run_api.py MID-API-001
```

Emulator (AVD `Pixel_7a`) และ Metro:

```powershell
npx expo start --offline --port 8081
```

- `adb reverse tcp:8081 tcp:8081` แล้วเปิด `exp://127.0.0.1:8081` ใน Expo Go · เปิด Airplane mode ก่อนเทสชีต 1
- ถ้าจอทึบแตะไม่ติด คือเมนู Expo Go ค้าง กดปุ่มเมนู (`keyevent 82`) ไม่ใช่บั๊กของแอป
- ห้ามใช้ `--localhost` คู่กับ `--offline` และถ้าไม่ใส่ `--offline` จะถามบัญชี Expo
- ผลของ `run_onb.py` อยู่ใน `evidence/_queue_onb.json` ต้องดูก่อนแล้วค่อยบันทึกด้วย `rec`
- ML: ใช้ `fall_detection_backend/ml_service/.venv` และตั้ง `PYTHONUTF8=1` โมเดล 3 ไฟล์อยู่ใน `models/` แล้ว
- `.qa-worktree` เป็นโค้ดก่อนเปลี่ยนหน้า login ห้ามใช้เทส
